# CMS by Surely

A frontend construction-management prototype built with React, TypeScript and Vite. Sample screens cover vendors, materials, sites, receipts, monthly ledgers, reports and a project showcase.

This is a browser-local portfolio demonstration. It has no backend, cloud database, account authentication or multi-user security. Changes stay in the current browser's local storage; use fictional records only. It is not production accounting software.

## Run

Run `npm ci`, then `npm run dev -- --port 4200`. Build with `npm run build` and run existing tests with `npm test`.

The showcase uses Surely branding, an independent local-storage key and route-loading feedback. The original active CMS application and archived prototype remain untouched. Publishing and deployment are separate steps.

PMS is excluded from the current portfolio showcase.
